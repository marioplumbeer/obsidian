# Obsidian

My personal knowledge vault. Notes go in when something is worth keeping.
The goal is to be able to find it, use it, and build on it later.

---

## Structure

| Folder | What goes here |
|---|---|
| `people/` | Notes on specific people — one subfolder per person |
| `leadership/` | Frameworks, tools, and references for leading teams |
| `engineering/` | Engineering practices and technical topics not tied to a person |
| `product/` | Product frameworks |
| `startups/` | Startup advice, business models, and founder stories |
| `child-development/` | Research and frameworks on child development and play |
| `how-2-fail/` | Notes on failure, risk-taking, and resilience |
| `Inbox/` | Unsorted notes awaiting filing into a topic folder |

### References & Citations

Cite sources inline, at the point where you mention them:
- **External sources** (articles, videos, primary sources) — link directly: `[Redis](https://redis.io)`
- **Other vault notes** — use a wikilink: `[[pragmatic-engineer-interview]]`

External links belong in the prose where the claim is made. Reserve the `## References` section for the source material itself and vault wikilinks.

---

## Rules

- **Lowercase folders, always.** `people/` not `People/`
- **One file per source, one file per topic.** Don't mix them.
- **Topics are living documents.** Add new sources over time, don't create duplicates.
